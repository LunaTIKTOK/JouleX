# JouleX Sandbox

A **functioning** paper-trading sandbox for JouleX — not a mock. The
visitor creates markets, places paper orders against the real LMSR
pricing, settles via the AESO-oracle rule, runs the real flexibility
scheduler, and watches the HCS-schema audit log grow. Built
2026-11-12, on the owner's order: a working sandbox website until
real Alberta power suppliers and data centres are onboarded with
real-time data and liquidity.

## Files

| File | What it is |
|---|---|
| `joulex-sandbox.html` | The built single-file app (123 KB). Generated by `build_html.py` — never hand-edit. |
| `build_html.py` | Assembles the HTML from the tested sources below. |
| `build_data.py` | Generates `data.json` from the real JouleX modules + a live AESO snapshot. Re-run to refresh. |
| `data.json` | Synthetic 14-day series, live AESO snapshot (Nov 12, 2026), 24 scheduler jobs, seed markets/trades. |
| `lmsr.js` | LMSR port, 1:1 from `joulex/lmsr.py` (incl. Python round-half-even). |
| `sha256.js` | Sync SHA-256 + JCS canonical JSON matching `joulex/attestation.py` byte-for-byte. |
| `scheduler.js` | Orchestrator port, 1:1 from `joulex/orchestrator.py`. |
| `engine.js` | Sandbox exchange: markets, ledger, settlement, HCS local log. Same rules as `joulex/{exchange,markets,ledger,hcs,aeso}.py`. |
| `app.js` | Browser UI layer (no pricing math — that lives in the engine). |
| `tests/gen_expected.py` | Ground truth from the real Python modules. |
| `tests/expected.json` | Generated expectations (300 LMSR cases, hash cases, orchestrator result). |
| `tests/parity.cjs` | Node parity test: JS ports vs Python ground truth. |
| `tests/exercise.cjs` | Node end-to-end engine exercise (trade/settle/errors/conservation/log). |
| `tests/smoke.cjs` | Headless-browser (jsdom) click-through of the built HTML. Needs `npm install jsdom`. |

## What is real vs simulated

- **Real:** LMSR math, market/order/settlement/ledger rules, the
  scheduler algorithm, the live AESO snapshot (4 hourly prices
  fetched Nov 12 ~08:47 MT, parsed with the oracle's own code).
- **Synthetic (labelled):** the 14-day price series (built from
  verified 2025 AESO stats: mean $43.68/MWh, 10.6% zero hours,
  $999.99 cap).
- **Simulated:** all traders, liquidity, counterparties; the HCS log
  is local-only (live path: Hedera testnet topic 0.0.11399235).
- **Bypassed (labelled):** CF-KYA admission, operator key,
  attestation envelopes — production requires all three.

## Refreshing the live snapshot

```sh
curl -sS -o /tmp/smp.csv --max-time 15 \
  "http://ets.aeso.ca/ets_web/ip/Market/Reports/CSMPriceReportServlet?contentType=csv" \
  -H "User-Agent: joulex/0.1 (non-commercial research prototype)"
# update LIVE_FETCHED_AT in build_data.py to the response Date header
python3 build_data.py && python3 build_html.py
node tests/parity.cjs && node tests/exercise.cjs
```
